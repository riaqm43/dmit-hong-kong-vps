## AN5 和 AS3 怎么选？

这是另一个容易被忽略的区别。

DMIT 香港节点当前同时提供 AN5 和 AS3。官方对两种平台的定位也很直接：AN5 使用 **AMD EPYC 9005 Series**，AS3 使用 **AMD EPYC 7003 Series**；官方把 AN5 描述为旗舰平台，而 AS3 则强调成熟、稳定以及更高的价格竞争力。

从香港 Premium 页面来看，AN5 档直接从 MINI 起步，价格也明显高于 AS3 Premium。换句话说，如果你真正关心的是 CPU 单核、多核性能以及新一代平台，而预算允许，AN5 是更高一档的硬件平台；如果工作负载比较普通，AS3 已经覆盖了大量常见场景。

这类差异最适合放到具体业务上理解。

WordPress、小型企业网站、个人博客、监控节点、轻量 API，通常没必要一开始就买到 8 核甚至 12 核。

数据库、多个容器、编译环境、后台任务并行明显增加之后，内存和 CPU 才开始值得上探。

而且不要忘记，**更高配置不会自动解决线路问题**。一个 12 vCore 的服务器如果业务访问路径本身不理想，CPU 再多也不能把网络距离压缩掉。

## “香港服务器推荐”里最容易被忽略的流量限制

很多套餐表只写“流量 2TB”“带宽 10Gbps”，看起来很爽，但真正下单时一定要把这两个数字分开看。

Tier 1 当前大量产品的流量口径是 `Max(IN, OUT)`。例如 TINY 是 2000GB，STARTER 是 4000GB，MEDIUM 是 32000GB，GIANT 是 128000GB；而端口则从 4Gbps 到 10Gbps。

这类“10Gbps”也不意味着你每天下载都能稳定跑满 10Gbps。DMIT 对端口数字的定义属于峰值能力，实际网络速率会受到虚拟机性能、国际网络环境和本地网络环境影响。官网也明确提醒，这类数字是参考值，并非实际速率承诺。

对于博客、企业官网、管理后台来说，这通常不是最先需要考虑的问题。

对于视频、文件分发、备份、镜像同步、大规模 API 流量，则必须把流量额度和端口峰值一起看。
